## RECORDING CHECKLIST

- [ ] Clear browser cache
- [ ] Close unnecessary tabs
- [ ] Run dev server (ensure fast loading)
- [ ] Pre-populate demo data in each module
- [ ] Test language switching works smoothly
- [ ] Test screen recording software
- [ ] Microphone check (no background noise)

### Technical Requirements:
- Resolution: 1920x1080 minimum
- Frame rate: 30fps or 60fps
- Audio: Clear voiceover, light background music
- Editing: Quick cuts, no dead air, text overlays for emphasis

## ALTERNATIVE: NO-EDIT VERSION

If you don't have editing software, here's a simpler approach:

1. Practice the script until you can do it in one take
2. Use OBS Studio (free) to record screen + mic
3. Record 3-4 takes, use the best one
4. Upload directly without editing

The content matters more than production quality at seed stage.
